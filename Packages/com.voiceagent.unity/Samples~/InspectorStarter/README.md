# Inspector Starter

This sample gives you a ready-made prefab:

- `VoiceAgent Sample.prefab`

It already has `VoiceAgentComponent` attached with practical defaults:

- host: `127.0.0.1`
- panel port: `8787`
- backend: `piper`
- voice: `en_US`
- Kokoro voice: `af_heart`
- reply mapping example: when the detected user reply is `test`, the sample plays `I hear that.`

## Use

1. Import this sample from Package Manager.
2. Drag `VoiceAgent Sample.prefab` into your scene.
3. Select it.
4. Use the buttons on the right-side Inspector to call the runtime directly.
